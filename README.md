# Πρόοδος Πτυχίου ICE

Ανεπίσημο εργαλείο για φοιτητές του [Τμήματος Μηχανικών Πληροφορικής και Υπολογιστών](https://ice.uniwa.gr/) του ΠΑΔΑ.
Φορτώνεις την καρτέλα σου από το φοιτητολόγιο και βλέπεις:

- ποια μαθήματα έχεις περάσει και πώς μετράνε στο πτυχίο (Υποχρεωτικά, Βασικά Ροής, ΕΥ, Γενικής Παιδείας),
- τι σου λείπει για να πάρεις πτυχίο, με βάση τους κανόνες του προγράμματος σπουδών,
- τον βαθμό πτυχίου σήμερα, και πώς αλλάζει αν γράψεις προβλεπόμενους βαθμούς στα μαθήματα που μένουν,
- τι μέσο όρο χρειάζεσαι στα υπόλοιπα για να πιάσεις έναν στόχο.

**Η καρτέλα σου δεν ανεβαίνει πουθενά.** Όλα τρέχουν μέσα στον browser σου.

## Χρήση

1. Στο φοιτητολόγιο, άνοιξε «Η καρτέλα μου» → «Όλα τα μαθήματα» και κατέβασέ την σε Excel (.xlsx).
2. Άνοιξε τη σελίδα του εργαλείου και πάτα «Φόρτωσε την καρτέλα σου».
3. Διάλεξε ροή (μαντεύεται αυτόματα) και, αν κάνεις Πρακτική Άσκηση, τσέκαρε την επιλογή.
4. Γράψε βαθμούς στα μαθήματα που λείπουν για να δεις τον βαθμό πτυχίου που θα βγάλεις.

Η καρτέλα και οι προβλέψεις αποθηκεύονται μόνο στον browser σου (localStorage), ώστε να τις βρεις την επόμενη φορά.

## Πώς υπολογίζεται ο βαθμός

Βαθμός πτυχίου = Σ(βαθμός × ECTS) / Σ ECTS, για τα 55 μαθήματα που μετράνε στο πτυχίο και τη Διπλωματική.
Αν έχεις περάσει παραπάνω ΕΥ από όσα χρειάζονται, το εργαλείο κρατάει τα καλύτερα που επιτρέπουν οι κανόνες
(τουλάχιστον 5 της ροής, το πολύ 7 εκτός ροής, το πολύ 2 Γενικής Παιδείας) και δείχνει τα υπόλοιπα ως «εκτός Μ.Ο.».
Ποια μαθήματα εξαιρούνται τελικά το δηλώνεις στη Γραμματεία. Ο επίσημος βαθμός είναι πάντα αυτός της Γραμματείας.

## Αν άλλαξε το πρόγραμμα σπουδών

Όλοι οι κανόνες και τα μαθήματα βρίσκονται στο [`js/curriculum.js`](js/curriculum.js). Αν κάτι άλλαξε,
διόρθωσέ το εκεί και άνοιξε pull request. Αν ένα μάθημα της καρτέλας σου δεν αναγνωρίζεται, άνοιξε issue
με το όνομά του όπως εμφανίζεται στην καρτέλα (χωρίς βαθμούς).

## Για developers

Στατική σελίδα χωρίς build step και χωρίς dependencies. Η ανάγνωση του Excel γίνεται με [SheetJS](https://sheetjs.com/) από το CDN τους.

```
index.html          σελίδα
css/styles.css      εμφάνιση (παλέτα Figma "Ink wash")
js/curriculum.js    πρόγραμμα σπουδών και κανόνες
js/degree.js        λογική (χωρίς DOM, με tests)
js/app.js           διεπαφή
js/sample.js        φανταστική καρτέλα για επίδειξη
test/               node --test
```

Τοπικά: άνοιξε το `index.html` στον browser, ή τρέξε `python3 -m http.server` και πήγαινε στο http://localhost:8000.
Tests: `node --test` (Node 20+).

### Δημοσίευση με GitHub Pages

Settings → Pages → Source: «Deploy from a branch» → Branch: `main`, φάκελος `/ (root)`.
Η σελίδα θα είναι στο `https://<username>.github.io/<repo>/`.
